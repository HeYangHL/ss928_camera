# 追踪算法优化方案

## 一、现状分析

### 1.1 当前代码架构

```
pch.cpp::TrakingCarsID()
├── 初始化：第1帧创建KalmanTracker
├── 预测：调用predict()更新m_time_since_update
├── 匈牙利匹配：assignment[i] = 匹配检测索引
├── 阈值过滤：IOU < iouThreshold视为无效匹配
├── 更新：matched检测更新tracker
├── 新增：unmatchedDetections创建新tracker
└── 清理：m_time_since_update >= max_lost_age删除
```

### 1.2 存在的问题

| 问题 | 根因 | 影响 |
|------|------|------|
| 静态物体被当作运动物体 | `is_move`标志从未更新为false | 卡尔曼滤波器预测位置漂移 |
| 延迟清除 | `unmatchedTrajectories`未使用 | 摄像机移动后旧rgn残留 |
| 无相机移动检测 | 完全没有相关逻辑 | 无法区分目标消失和相机移动 |

```cpp
void KalmanTracker::check_static_state()
{
    if (m_time_since_update > 0) {
        return;
    }
    
    float vx, vy;
    get_state(vx, vy);
    float speed = sqrt(vx * vx + vy * vy);
    
    if (speed < velocity_threshold) {
        static_confirm_hits++;
    } else {
        static_confirm_hits = 0;
        is_static = false;
    }
    
    if (static_confirm_hits >= 5) {
        is_static = true;
    }
}

bool KalmanTracker::get_static_flag()
{
    return is_static;
}

void KalmanTracker::reset_static_history()
{
    static_confirm_hits = 0;
    is_static = false;
}
```

```cpp
#include "CameraMotionDetector.h"

CameraMotionDetector::CameraMotionDetector()
{
    motion_threshold = 10;
    motion_ratio = 0.7f;
    consecutive_frames = 3;
    motion_count = 0;
}

bool CameraMotionDetector::detectMotion(const cv::Mat& prev_frame, const cv::Mat& curr_frame)
{
    cv::Mat curr_gray;
    cvtColor(curr_frame, curr_gray, cv::COLOR_BGR2GRAY);
    
    if (prev_gray.empty()) {
        prev_gray = curr_gray.clone();
        return false;
    }
    
    std::vector<cv::Point2f> prev_pts, curr_pts;
    goodFeaturesToTrack(prev_gray, prev_pts, 200, 0.01, 30);
    
    if (prev_pts.empty()) {
        prev_gray = curr_gray.clone();
        return false;
    }
    
    std::vector<uchar> status;
    std::vector<float> err;
    calcOpticalFlowPyrLK(prev_gray, curr_gray, prev_pts, curr_pts, status, err);
    
    std::vector<cv::Point2f> valid_flows;
    for (size_t i = 0; i < status.size(); i++) {
        if (status[i]) {
            cv::Point2f flow = curr_pts[i] - prev_pts[i];
            float flow_mag = norm(flow);
            if (flow_mag > 1.0f && flow_mag < 100.0f) {
                valid_flows.push_back(flow);
            }
        }
    }
    
    if (valid_flows.size() < 20) {
        prev_gray = curr_gray.clone();
        return false;
    }
    
    std::sort(valid_flows.begin(), valid_flows.end(), 
        [](const cv::Point2f& a, const cv::Point2f& b) {
            return norm(a) < norm(b);
        });
    
    cv::Point2f median_flow = valid_flows[valid_flows.size() / 2];
    float median_mag = norm(median_flow);
    
    int consistent_count = 0;
    for (const auto& flow : valid_flows) {
        float angle_diff = abs(atan2(flow.y, flow.x) - atan2(median_flow.y, median_flow.x));
        if (angle_diff < CV_PI / 4 || angle_diff > 2 * CV_PI - CV_PI / 4) {
            consistent_count++;
        }
    }
    
    float consistent_ratio = (float)consistent_count / valid_flows.size();
    
    last_motion_vector = median_flow;
    prev_gray = curr_gray.clone();
    
    if (median_mag > motion_threshold && consistent_ratio > motion_ratio) {
        motion_count++;
        if (motion_count >= consecutive_frames) {
            return true;
        }
    } else {
        motion_count = 0;
    }
    
    return false;
}

cv::Point2f CameraMotionDetector::getMotionVector()
{
    return last_motion_vector;
}

bool CameraMotionDetector::isCameraMoved()
{
    return motion_count >= consecutive_frames;
}

void CameraMotionDetector::reset()
{
    motion_count = 0;
    prev_gray.release();
}
```

### 3.2 三种相机移动处理方案对比

| 方案 | 清除策略 | 优点 | 缺点 | 适用场景 |
|------|----------|------|------|----------|
| **方案A** | 选择性清除（未确认轨迹） | 保留长期跟踪目标，用户体验好 | 实现稍复杂，可能误判 | 固定场景偶尔移动 |
| **方案B** | 完全清除重建 | 实现简单，完全干净 | 丢失所有ID，用户体验差 | PTZ快速移动 |
| **方案C** | 运动补偿+局部清除 | 最智能，保留尽可能多目标 | 实现最复杂，性能开销大 | 持续小幅移动 |

---

### 3.3 方案A详细实现：选择性清除

**策略**：
- 区分"已确认轨迹"（m_hit_streak >= N）和"未确认轨迹"
- 相机移动时，只清除未确认轨迹
- 已确认轨迹重置预测历史，利用新位置的检测框重新匹配

```cpp
// pch.cpp 新增
static void handleCameraMotion_MotionCompensation(CarTracking *p_car, cv::Point2f& motion_vector)
{
    printf("Camera motion detected, applying motion compensation...\n");
    
    vector<KalmanTracker> &trackers = p_car->trackers;
    int confirmed_threshold = p_car->param.confirmed_hits_threshold;
    
    vector<KalmanTracker> confirmed_trackers;
    
    for (auto &trk : trackers) {
        if (trk.m_hit_streak >= confirmed_threshold) {
            // 获取当前状态
            float vx, vy;
            cv::Rect_<float> state = trk.get_state(vx, vy);
            
            // 应用运动补偿
            state.x -= motion_vector.x;
            state.y -= motion_vector.y;
            state.x = max(0.0f, state.x);
            state.y = max(0.0f, state.y);
            
            // 重新初始化卡尔曼滤波器状态
            trk.init_kf(state);
            trk.m_time_since_update = 0;
            trk.m_history.clear();
            if (trk.get_static_flag()) {
                trk.reset_static_history();
            }
            
            confirmed_trackers.push_back(trk);
        }
    }
    
    trackers = confirmed_trackers;
    
    printf("Motion compensated %d trackers\n", (int)confirmed_trackers.size());
}
```

## 七、注意事项

1. **相机移动检测需要当前帧图像**：方案A/B/C都需要传入原始帧数据用于光流计算
2. **性能考虑**：光流计算有一定开销，建议每N帧检测一次而非每帧检测
3. **参数调优**：不同场景（室内/室外/停车场）需要调整 `velocity_threshold` 和 `confirmed_hits_threshold`
4. **测试建议**：先实现方案A，如果用户反馈仍有问题再考虑方案C
